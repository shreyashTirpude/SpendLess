STEP 2: INTERACT WITH THE APP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Once the app is running on your emulator/device, try:

  1. Splash Screen
     → See SpendLens logo for 2 seconds

  2. Onboarding (4 slides)
     → Swipe through features
     → Tap "Get Started"

  3. Authentication
     → Enter phone +91 9876543210
     → Or click "Email" tab for signup

  4. Dashboard (Home)
     → See spent/income cards
     → View recent transactions

  5. Navigation (Bottom 5 Tabs)
     🏠  Home          → Dashboard
     📋 Transactions  → All transactions with date grouping
     💰 Budget        → Monthly budget tracking
     📈 Insights      → Analytics & top merchants
     ⚙️  Settings      → Profile, security, notifications

  6. Interactive Features
     → Tap [+] FAB to add manual transaction
     → Toggle "Biometric Lock" in Settings
     → Tap "Export Data" to download CSV
     → Scroll through budget progress bars
